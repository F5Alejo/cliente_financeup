1. Cómo se reparten las responsabilidades

Regla para todos los mapas: el cliente nunca habla con la base de datos, y el CRUD nunca decide reglas de negocio.

Cliente (Angular)Muestra pantallas y envía peticiones al MID con el token de sesión. No calcula totales ni valida permisos.
MIDValida permisos (403), revisa datos (422) y duplicados (409), une varias tablas, calcula (totales, porcentajes) y, si una escritura falla a la mitad, deshace lo anterior (rollback).
CRUDUn recurso por tabla: GET/POST/PUT/DELETE /crud/<tabla>. Solo guarda y lee, sin reglas de negocio.
Base de datosLas 15 tablas de la sección 3. Cada mapa indica cuáles toca.
